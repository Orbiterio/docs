<Warning>
**Bake-off rules — mandatory for every lane, every phase (Mark, 2026-09-06).** Provider and model choices named on this page are *defaults to beat*, not decisions. Before a provider or model is wired into a code path, run the bake-off below on the lane's own Phase 0 fixtures, record the result on this page (a dated table: candidates, fixture set, quality metric, cost per 1K calls, the pick and why), and only then set the config value.

1. **Web search: Exa vs. [Parallel Search](https://parallel.ai/products/search).** Every search-shaped step — profile discovery, page discovery, corroboration lookups — is run against **both** on the same fixture queries, scored on the lane's task (e.g. correct LinkedIn profile in the top *n*, honor-roll page found, surname-in-slug precision), and the better one for **that task** is chosen. Neither is the house default; a lane may pick Exa for one step and Parallel for another. Wire the client behind the lane's search seam so the loser can be swapped back in without touching the pipeline. Parallel's own published benchmarks (HLE, BrowseComp, SimpleQA — Nov 2025) are context, not a result: the bake-off is on our data.
2. **LLM models: at least THREE OpenRouter alternatives per call site.** Every LLM step (extraction, title→role classification, adjudication, description generation) is baked off across **≥ 3 models** from the [OpenRouter](https://openrouter.ai/models) catalogue on the labelled Phase 0 set. Score **quality first** (task accuracy / agreement with the labelled set / structured-output validity), **price second** (per 1K calls at the real prompt sizes). Quality outranks price: a cheaper model wins only when its quality is within the lane's stated tolerance of the best — never on price alone. Include one frontier model as the quality ceiling, one mid-tier, and one budget model; record temperature, reasoning on/off and `max_tokens` used, because they change both axes.
3. **Re-run when the world changes.** A new model generation, a provider price change, or a measured quality regression re-opens the bake-off for that call site. The dated table on the page is the audit trail.
</Warning>
