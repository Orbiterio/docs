This is the current **Ryan Reynolds / Maximum Effort** outcome suggestion design, captured on September 14, 2026. It uses the **Midnight** palette, a **1px border around WHY**, and **10px spacing above each content section**.

[Open the editable design](http://localhost:3002/) · [Compare palettes](http://localhost:3002/palettes.html) · [Sample outcome payload](/guides/open-work/suggestion-delivery-and-tables/sample-suggestion-data#outcome)

The screenshots show the UI prototype. The delivery payload remains documented on the parent page; the sample narrative here is a design example.

## Default view

The main opportunity starts open. WHY stays visible; Trajectory, Suggested Sequencing, and each action's alternatives start closed. Each trajectory shows its top action, **Draft Email**.

## Open and closed states

| Control | Closed state | Open state |
| --- | --- | --- |
| Main opportunity | Moonshot badge and Ryan Reynolds / Maximum Effort title | Profile, WHY, Trajectory, Suggested Sequencing, and Action |
| Trajectory | Charlie Anderson & Kyle Jackson | Separate route narratives and both profile cards |
| Suggested Sequencing | Start with Charlie | All three numbered outreach steps |
| Charlie action chevron | Top email action | Email plus an SMS alternative for Charlie |
| Kyle action chevron | Top email action | Email plus an SMS alternative for Kyle |
| Email or SMS button | No composer | Editable local draft with copy and close controls |
| Other opportunities | Opportunity title | Placeholder notes field |
| Archived | Label and count | Empty sample message |

WHY has no independent collapse control. Closing the main opportunity hides it with the rest of the opportunity.

### Recipient options

The UI defaults to the first entry in `params.emails[]` or `params.mobile_phones[]`. Charlie’s single email and mobile number appear as fixed fields. Kyle’s two emails and two mobile numbers appear as dropdowns, preserving the order supplied. Choose one option for the current draft; switching recipients does not change the stored option arrays. Refresh resets the selection to the first option.

Kyle’s email defaults to `kyledeanjackson@gmail.com`, with `kyle@beinghuman.studio` as the alternative. His mobile defaults to `+13234526998`, with `+6588333422` as the alternative. All mobile numbers use E.164. The [sample payloads](/guides/open-work/suggestion-delivery-and-tables/sample-suggestion-data#recipient-options) contain the complete contact arrays.

## CSS reference

| Section | Background | Border | Accent |
| --- | --- | --- | --- |
| WHY | `#172440` | `#7899da` | `#adc9ff` |
| Trajectory | `#271f32` | `#5c466a` | `#ceb5e0` |
| Suggested Sequencing | `#292316` | `#635334` | `#d8bb7a` |
| Action | `#14323b` | `#3e7380` | `#b0dce3` |

WHY uses a 1px border on all four edges. Content sections use a 10px top gap. The HTML scopes the UI styles under `#orbiter-moonshot` and includes the responsive rules from the current prototype.

## Copyable HTML file

[Download the HTML and image bundle (ZIP)](/images/suggestion-delivery/outcome-ui-reference.zip), extract it, then open `outcome-ui-reference.html` in a browser. Keep `current-ui.png` beside it for profile photos and logos. You can also copy the code below and save [the profile image sprite](/images/suggestion-delivery/current-ui.png) alongside your HTML file.

The file includes HTML, CSS, and plain JavaScript for the accordions and local drafts. It needs no React runtime or build step. The prototype's palette and copy-editing toolbar is omitted; the suggestion board is preserved.

const referenceRecipientSelections = {};
function createReferenceRecipients(personIds, channel) {
  const element = document.createElement('div');
  element.className = 'orb-recipient-fields';
  const controls = [];
  personIds.forEach(personId => {
    const person = referenceContacts[personId];
    const options = person[channel === 'sms' ? 'mobile_phones' : 'emails'];
    const key = channel + ':' + personId;
    const selected = options.includes(referenceRecipientSelections[key]) ? referenceRecipientSelections[key] : options[0];
    const field = document.createElement('div');
    field.className = 'orb-recipient-field';
    const label = document.createElement('label');
    label.htmlFor = 'recipient-' + channel + '-' + personId;
    label.textContent = (channel === 'sms' ? 'Mobile' : 'To') + ' — ' + person.name;
    const input = document.createElement(options.length > 1 ? 'select' : 'input');
    input.id = label.htmlFor;
    if (options.length > 1) {
      options.forEach(value => {
        const option = document.createElement('option');
        option.value = value;
        option.textContent = value;
        input.append(option);
      });
      input.addEventListener('change', () => {
        referenceRecipientSelections[key] = input.value;
        const status = element.closest('.orb-composer')?.querySelector('.orb-copy-status');
        if (status) status.textContent = '';
      });
    } else {
      input.type = channel === 'sms' ? 'tel' : 'email';
      input.readOnly = true;
    }
    input.value = selected;
    controls.push(input);
    field.append(label, input);
    element.append(field);
  });
  return { element, values: () => controls.map(input => input.value) };
}
