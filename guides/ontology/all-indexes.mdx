## NEW UNIVERSE INDEXES

One idempotent script that provisions every index the Universe graph needs. Paste it into any FalkorDB graph (a fresh environment, a rebuilt graph, or an existing one): a statement whose index already exists returns "already indexed" and changes nothing. Indexes do not enforce uniqueness. Verify with `CALL db.indexes()` afterwards.

```cypher
// ── Identity keys on the shared Entity label ──────────────────────────────
CREATE INDEX FOR (n:Entity) ON (n.uuid);
CREATE INDEX FOR (n:Entity) ON (n.entity_id);
CREATE INDEX FOR (n:Entity) ON (n.merge_key);
CREATE INDEX FOR (n:Entity) ON (n.canonical_identity_key);
CREATE INDEX FOR (n:Entity) ON (n.city_key);
CREATE INDEX FOR (n:Entity) ON (n.region_key);
CREATE INDEX FOR (n:Entity) ON (n.thesis_id);

// ── Labels whose patterns never name Entity ───────────────────────────────
CREATE INDEX FOR (n:Funding_Round) ON (n.uuid);
CREATE INDEX FOR (n:Company) ON (n.uuid);
CREATE INDEX FOR (n:Event) ON (n.uuid);
CREATE INDEX FOR (n:Event) ON (n.event_key);
CREATE INDEX FOR (n:MediaAppearance) ON (n.media_key);
CREATE INDEX FOR (n:MediaAppearance) ON (n.uuid);
CREATE INDEX FOR (n:Release) ON (n.row_id);
CREATE INDEX FOR (n:Release) ON (n.uuid);
CREATE INDEX FOR (n:Place) ON (n.row_id);
CREATE INDEX FOR (n:Place) ON (n.uuid);
CREATE INDEX FOR (n:Stage_Award) ON (n.award_entry_key);
CREATE INDEX FOR (n:Stage_Award) ON (n.uuid);

// ── Vector indexes (Gemini 1536-dim, cosine) ─────────────────────────────
CREATE VECTOR INDEX FOR (n:Entity) ON (n.embeddings)
OPTIONS {
  dimension: 1536,
  similarityFunction: 'cosine',
  M: 16,
  efConstruction: 200,
  efRuntime: 10
};

CREATE VECTOR INDEX FOR (n:Entity) ON (n.expert_embeddings)
OPTIONS {
  dimension: 1536,
  similarityFunction: 'cosine',
  M: 16,
  efConstruction: 200,
  efRuntime: 10
};
```
