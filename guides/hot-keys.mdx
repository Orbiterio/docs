This page lists every hot key the Orbiter.io frontend assigns, grouped the way the Command Palette groups them, followed by the operating-system and browser shortcuts a new hot key must not collide with.

<Info>
Originally inventoried from `orbiter-frontend` on `thursday_dev` at `9b0ac5c3`. Updated 2026-09-26 to match the local frontend changes: Discover is **G then D**, Outcomes is **G then O**, and Leverage Loops is **G then L**. When you add, change or remove a hot key, update this page in the same change.
</Info>

Every Command Palette command has a hot key, and the palette shows each one as a badge beside the command.

**How to read the keys.** <kbd>⌘</kbd> is written `mod` in code: Command on a Mac, Ctrl on Windows and Linux. <kbd>⌥</kbd> is Option (Alt), <kbd>⇧</kbd> is Shift, <kbd>⌃</kbd> is Control.

## How hot keys work in the app

<Note>
There is **no central hot key system**. Orbiter does not use a TanStack hotkeys package; four mechanisms each own a slice, and the Command Palette registry is the closest thing to a single list.

1. **The Command Palette registry (`react-hotkeys-hook`).** Each command in `src/features/command-palette/constants/commands.tsx` carries `hotkey` (the binding, e.g. `mod+alt+o`, or `g>i` for a sequence) and `shortcut` (the badge text, e.g. `⌘⌥O`, or `G I`, which the badge draws as "G then I"). `useCommandHotkeys`, mounted once in `src/routes/_authed.tsx`, registers every command's `hotkey` with `useHotkeys`. Two fields means the badge and the binding can drift; keep them in step. `react-hotkeys-hook` skips text fields and contenteditable by default, so these never fire while typing, including in the notes editor. A few feature screens call `useHotkeys` directly too (Collections canvas, Email thread list).
2. **Hand-written `keydown` listeners.** <kbd>⌘</kbd> <kbd>K</kbd> is a window listener in the capture phase, so it wins over everything and works inside inputs. The Calendar <kbd>0</kbd> / <kbd>0</kbd> <kbd>0</kbd> controller, the Calendar view keys, the Activity arrows and the various <kbd>Esc</kbd>-to-close panels are plain `document`/`window` listeners that do their own "am I in a text field or dialog?" checks.
3. **Tiptap (ProseMirror keymaps) in the notes editor.** Tiptap manages the formatting keys itself: StarterKit and each extension (bold, italic, headings, lists, blockquote, code block, text align, highlight, sub/superscript) binds its own keys, and only while the editor has focus. The toolbar's `*_SHORTCUT_KEY(S)` constants are just the tooltip text for those. The editor's non-formatting actions (emoji, mention, slash menu, Ask AI, image, duplicate, copy, delete) are bound with `useHotkeys` in each button's hook, enabled on contenteditable.
4. **Component-local handlers.** `onKeyDown` on a single input (<kbd>Enter</kbd> to send, <kbd>⇧</kbd> <kbd>Enter</kbd> for a new line, <kbd>⌘</kbd> <kbd>Enter</kbd> in the suggestion composer), the palette's own list keys (built into `cmdk`), and `is-hotkey` in the editor's AI menu input.

**Spell punctuation by key name.** `react-hotkeys-hook` matches the physical key code, so bind `mod+slash`, `mod+shift+period`, `mod+backslash`, `mod+shift+semicolon`, never `mod+/` or `mod+shift+.`, which silently never fire. Tests in `commands.test.tsx` and `tiptap-editor/lib/hotkey-bindings.test.ts` enforce this, and `commands.test.tsx` also fails if any palette command is left without a hot key.

**Adding a global hot key:** add `hotkey` and `shortcut` to its command in `commands.tsx`, check it against every table on this page (including [System OS Hotkeys](#system-os-hotkeys)), then list it here.
</Note>

**Typing is safe.** Single-key and <kbd>⇧</kbd>-letter hot keys never fire while the cursor is in a text field, the notes editor, or an open dialog or palette.

## Command Palette

The palette opens from anywhere signed in. Its tabs are **All**, **Quick Actions**, **Navigation**, **People**, **Collections** and **Companies**. The **All** tab starts with recent commands (or a few Quick Actions before you have any history) and a **Go to** group. Search or choose a category to see the full command list.

The highlighted command expands inline with a short description, larger key badges, and a plain-language explanation: **press together** for modifier combinations, or **one key at a time** for sequences. Search also recognizes intent words, such as “draft” for Email Composer. Recent commands are stored locally per account.

| Move through results | <kbd>↑</kbd> / <kbd>↓</kbd> | <kbd>↑</kbd> / <kbd>↓</kbd> | Built into the palette (cmdk). |

## View sequences

The navigation keys follow Superhuman's "Go to" pattern (also used by Linear), so a Superhuman user already knows the gesture.

- **Email is <kbd>G</kbd> then <kbd>I</kbd>**, Superhuman's own "Go to Inbox".
- **Prefer memorable Orbiter initials:** <kbd>G</kbd> then <kbd>D</kbd> for Discover, <kbd>G</kbd> then <kbd>O</kbd> for Outcomes, and <kbd>G</kbd> then <kbd>L</kbd> for Leverage Loops. These replace G then F, G then U, and G then V. Press the two keys sequentially, not together.
- **These three sequences belong to global navigation.** Superhuman uses them for Drafts, Other, and Label; those email actions are not currently bound in Orbiter. If added later, resolve their scope or choose different keys rather than registering competing handlers.
- **A completed navigation sequence takes precedence over a Calendar view key.** Sequence listeners run in the capture phase and prevent the completed second key before view-level handlers run. <kbd>G</kbd> then <kbd>D</kbd> opens Discover without also switching Calendar to Day; a standalone <kbd>D</kbd> still selects Day view. An integration test covers both listener registration orders.
- Other mnemonics: <kbd>P</kbd> people (Contacts), <kbd>C</kbd> Collections, <kbd>B</kbd> briefing (Meeting Prep), <kbd>G</kbd> home (Activity).

The four actions that had none follow the palette's existing patterns: <kbd>⇧</kbd> plus a letter creates (Create Project <kbd>⇧</kbd> <kbd>P</kbd>, Create Task <kbd>⇧</kbd> <kbd>T</kbd>), <kbd>⌘</kbd> <kbd>⌥</kbd> plus a letter opens a manager (Projects & Tasks <kbd>⌘</kbd> <kbd>⌥</kbd> <kbd>P</kbd>), and X Followers & DMs takes <kbd>⌥</kbd> <kbd>⇧</kbd> <kbd>X</kbd> like New Contact.

**How it works:** sequences are `react-hotkeys-hook` bindings written `g>i`, registered by the same `useCommandHotkeys` as every other palette key. A sequence resets after a second or on a wrong key, and never fires while typing in a text field. The view letters live in `VIEW_SEQUENCE_KEYS` in `commands.tsx`.

Most Orbiter users already know Superhuman's keys, so the email and calendar features should reuse as many as possible. This is Superhuman Mail's own list ([v8, Mac edition](https://download.superhuman.com/Superhuman%20Keyboard%20Shortcuts.pdf)), mapped against Orbiter.

- <Same>✓ Green</Same>: same keys, same job in Orbiter today.
- <Clash>⚠ Amber</Clash>: Orbiter already uses these keys for something else. Resolve that before reusing them.
- Uncolored: free to reuse.

<Note>
Superhuman is a desktop app; Orbiter runs in the browser. Keys the browser owns (<kbd>⌘</kbd> <kbd>N</kbd>, <kbd>⌘</kbd> <kbd>T</kbd>, <kbd>⌘</kbd> <kbd>W</kbd>, <kbd>⌘</kbd> <kbd>1</kbd>–<kbd>9</kbd>, <kbd>⌘</kbd> <kbd>=</kbd> / <kbd>-</kbd> / <kbd>0</kbd>, <kbd>⌘</kbd> <kbd>[</kbd> / <kbd>]</kbd>) cannot be reused, and <kbd>⌃</kbd> <kbd>1</kbd>–<kbd>9</kbd> switches macOS Spaces. Single-letter keys are safe to reuse because Orbiter never fires them while you are typing; the <kbd>G</kbd> then <kbd>X</kbd> sequences need a sequence handler like the Calendar's <kbd>0</kbd> <kbd>0</kbd>.
</Note>

### Reuse notes

- **Calendar is nearly there.** <kbd>0</kbd>, <kbd>0</kbd> <kbd>0</kbd> and <kbd>T</kbd> already match. To finish: make <kbd>B</kbd> create an event and <kbd>P</kbd> / <kbd>N</kbd> (or <kbd>-</kbd> / <kbd>=</kbd>) move back and forward, which means moving "new event" off <kbd>N</kbd>.
- **Email has only <kbd>G</kbd> then <kbd>I</kbd> so far.** Superhuman's single-letter set (<kbd>E</kbd>, <kbd>H</kbd>, <kbd>R</kbd>, <kbd>F</kbd>, <kbd>C</kbd>, <kbd>J</kbd> / <kbd>K</kbd>, <kbd>U</kbd>, <kbd>S</kbd>, <kbd>#</kbd>, <kbd>L</kbd>, <kbd>/</kbd>) is free inside Orbiter and can be scoped to the Email view.
- **Three folder sequences are already global navigation:** <kbd>G</kbd> then <kbd>D</kbd> (Discover), <kbd>G</kbd> then <kbd>O</kbd> (Outcomes), and <kbd>G</kbd> then <kbd>L</kbd> (Leverage Loops). They cannot also open email Drafts, Other, or Label without an explicit scope change.
- **Four additional global keys block a straight copy:** <kbd>⇧</kbd> <kbd>C</kbd> (New Company), <kbd>⇧</kbd> <kbd>M</kbd> (Merge Contacts), <kbd>⌘</kbd> <kbd>⇧</kbd> <kbd>A</kbd> (Collections clear selection) and <kbd>⌘</kbd> <kbd>K</kbd> (palette, so no hyperlink key in editors). Either scope Superhuman keys to the Email view so they win there, or move the palette keys.
