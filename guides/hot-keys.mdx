This page lists every hot key the Orbiter.io frontend assigns, grouped the way the Command Palette groups them, followed by the operating-system and browser shortcuts a new hot key must not collide with.

<Info>
Inventoried from `orbiter-frontend` on `thursday_dev` at `79928213` (2026-09-26). When you add, change or remove a hot key, update this page in the same change.
</Info>

**How to read the keys.** <kbd>⌘</kbd> is written `mod` in code: Command on a Mac, Ctrl on Windows and Linux. <kbd>⌥</kbd> is Option (Alt), <kbd>⇧</kbd> is Shift, <kbd>⌃</kbd> is Control.

## How hot keys work in the app

<Note>
There is **no central hot key system**. Orbiter does not use a TanStack hotkeys package; four mechanisms each own a slice, and the Command Palette registry is the closest thing to a single list.

1. **The Command Palette registry (`react-hotkeys-hook`).** Each command in `src/features/command-palette/constants/commands.tsx` may carry `hotkey` (the binding, e.g. `mod+alt+o`) and `shortcut` (the badge text, e.g. `⌘⌥O`). `useCommandHotkeys`, mounted once in `src/routes/_authed.tsx`, registers every command's `hotkey` with `useHotkeys`. Two fields means the badge and the binding can drift; keep them in step. `react-hotkeys-hook` skips text fields and contenteditable by default, so these never fire while typing, including in the notes editor. A few feature screens call `useHotkeys` directly too (Collections canvas, Email thread list).
2. **Hand-written `keydown` listeners.** <kbd>⌘</kbd> <kbd>K</kbd> is a window listener in the capture phase, so it wins over everything and works inside inputs. The Calendar <kbd>0</kbd> / <kbd>0</kbd> <kbd>0</kbd> controller, the Calendar view keys, the Activity arrows and the various <kbd>Esc</kbd>-to-close panels are plain `document`/`window` listeners that do their own "am I in a text field or dialog?" checks.
3. **Tiptap (ProseMirror keymaps) in the notes editor.** Tiptap manages the formatting keys itself: StarterKit and each extension (bold, italic, headings, lists, blockquote, code block, text align, highlight, sub/superscript) binds its own keys, and only while the editor has focus. The toolbar's `*_SHORTCUT_KEY(S)` constants are just the tooltip text for those. The editor's non-formatting actions (emoji, mention, slash menu, Ask AI, image, duplicate, copy, delete) are bound with `useHotkeys` in each button's hook, enabled on contenteditable.
4. **Component-local handlers.** `onKeyDown` on a single input (<kbd>Enter</kbd> to send, <kbd>⇧</kbd> <kbd>Enter</kbd> for a new line, <kbd>⌘</kbd> <kbd>Enter</kbd> in the suggestion composer), the palette's own list keys (built into `cmdk`), and `is-hotkey` in the editor's AI menu input.

**Spell punctuation by key name.** `react-hotkeys-hook` matches the physical key code, so bind `mod+slash`, `mod+shift+period`, `mod+backslash`, `mod+shift+semicolon`, never `mod+/` or `mod+shift+.`, which silently never fire. Tests in `commands.test.tsx` and `tiptap-editor/lib/hotkey-bindings.test.ts` enforce this.

**Adding a global hot key:** add `hotkey` and `shortcut` to its command in `commands.tsx`, check it against every table on this page (including [System OS Hotkeys](#system-os-hotkeys)), then list it here.
</Note>

**Typing is safe.** Single-key and <kbd>⇧</kbd>-letter hot keys never fire while the cursor is in a text field, the notes editor, or an open dialog or palette.

## Command Palette

The palette opens from anywhere signed in. Its tabs are **All**, **Quick Actions**, **Navigation**, **People**, **Collections** and **Companies**, and each command shows its hot key as a badge.

## Navigation

The palette's **Navigation** commands open the workspace views: Discover, Outcomes, Leverage Loops, Collections, Serendipity, Activity, Contacts, Calendar, Email, Teams, Meeting Prep and Deal Flow. **None of them has a hot key**; open them from the palette. The only navigation hot keys are the Calendar ones below.

### Calendar

| Action | Keys | Where it works |
|---|---|---|
| Open Agenda side panel, on today | <kbd>0</kbd> | Anywhere signed in. On the Calendar route it opens the docked panel; elsewhere it opens as an overlay. |
| Open the Calendar view | <kbd>0</kbd> <kbd>0</kbd> | Anywhere signed in. Press 0 twice within 400 ms. |

The single <kbd>0</kbd> waits 400 ms before opening the agenda so a second <kbd>0</kbd> can cancel it; the agenda never flashes open on the way to the Calendar view. Defined in `src/features/calendar/shortcuts.ts`, installed by `CalendarSync`.

| Action | Keys |
|---|---|

Ignored while a card is open, while typing, and inside menus or dialogs; <kbd>↑</kbd> stops at today. The time-range dropdown shows the same two keys. Defined in `src/features/activities/components/orbits.tsx`.

### Email
